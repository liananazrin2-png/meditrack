
# MedTracker

Smart Medicine and Health Management System.

## About
MedTracker is a web-based application designed to
help users manage their medicines and maintain
basic health records.

## Features
- Medicine inventory management
- Medicine expiry date tracking
- Health record management
- Health measurement comparison
- Responsible medicine disposal tracking

## Technologies Used
- HTML
- CSS
- JavaScript
- Progressive Web App (PWA)

## Storage
The current demo stores information locally
in the browser using localStorage.

## Project Purpose
To provide a simple and user-friendly platform
for medicine and health record management.
